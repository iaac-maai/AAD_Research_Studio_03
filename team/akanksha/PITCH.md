# Thursday pitch

## 1. Problem

A 90-degree hook can open during an earthquake. It can lose confinement instead of holding the stirrup or tie around the column. Eurocode 8 calls for 135-degree hooks and a measured tail in critical regions.

The team is building a fast visual check for the cage before the pour. It is not a replacement for the engineer or site supervisor.

## 2. What the app does

The nine pipeline steps are:

1. Print four 100 mm markers.
2. Film or photograph the cage.
3. Extract a still frame.
4. Send the frame to the model server.
5. Detect bars, ties and hooks as outlines.
6. Convert the outlines to measurements.
7. Compare the cage with the bending schedule and Eurocode limits.
8. Produce fix instructions.
9. Let a person confirm or reject each fault and save the signed result.

## 3. Version 1

The Thursday demo will cover one column face and one still photo:

- detect marker scale;
- detect the rebar classes;
- check one face in an end or middle zone;
- show a green fine / red fault photo overlay;
- list fixes;
- require one person to confirm or reject each fault;
- save the reviewed result.

## 4. What it does not do

It does not approve the cage automatically. It does not certify that every face, hidden bar or structure has passed. It does not replace structural drawings or the engineer's national-annex review. It does not run 3D reconstruction, continuous live review or complete slab/footing analysis in version 1.
